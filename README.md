# Balon Durağı

Kaydırmalı balon eşleştirme oyunu. Oyunun tamamı tek dosya: `index.html`.

Yayın adresi: https://celiklioguzhan.github.io/balon-duragi/

Android uygulaması oyunu bu adresten yükler; buraya gönderilen her güncelleme, uygulamayı kullanan herkese bir sonraki açılışta ulaşır.

## Telefona kurmak (Android)

APK'yı indir: https://github.com/celiklioguzhan/balon-duragi/releases/latest/download/BalonDuragi.apk

Telefonda açınca "bilinmeyen kaynaktan yükleme" izni ister; izin verip kur. APK, `android/` klasöründen GitHub Actions ile otomatik derlenir; imza anahtarı depoda durmaz.
